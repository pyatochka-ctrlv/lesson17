# Музей пригод — гра для уроку 17

Інтерактивна гра для онлайн-уроку (Minecraft, 8 років). Відкрийте `index.html` подвійним кліком і покажіть вкладку через демонстрацію екрана. Для найкращого вигляду натисніть F11 (повний екран).

## Керування (тільки вчитель)

| Клавіша | Дія |
|---|---|
| Space | Показати відповідь; якщо вже показана — Далі (у раунді 4: відповідь → наповнити → далі) |
| H | Підказка (повторне натискання — наступна підказка / сховати) |
| → | Далі |
| ← | Назад |
| P | «Ще пікселі» (раунд 1) |
| 1–4 | Обрати варіант відповіді (раунди 3 і 4) |

На карті музею Space / Enter відкриває наступну залу. Клавіші працюють за будь-якої розкладки.

## Раунди
1. Вгадай піксель-арт — 4 картинки під «туманом» (на старті відкрито ~20% пікселів малюнка).
2. Знайди скриню — 3 скрині на сітці X −4…4, Y 0…6; вчитель клікає клітинку, яку назвали діти.
3. Правда чи міф? — 7 тверджень, варіанти «1 👍 Правда» / «2 👎 Міф».
4. Наповни зілля — 7 питань з пронумерованими варіантами; після відповіді «Наповнити» додає один рівень у пляшку.

Шрифти (Handjet, Nunito) підвантажуються з Google Fonts; без інтернету гра працює із системними шрифтами.
